# 再靠近一点

温柔的双人聊天网页：先选择「心动之间」或「朋友之间」，再选择话题类型，抽一个话题。

## 使用

通过 GitHub Pages 打开网页，或下载 `index.html` 后直接用浏览器打开。无需登录，也不需要安装。

- 纸卷、双爱心和双杯插画的欢迎选择页。
- 心动模式：暖粉纸卷轴，199 道题；保留原有进度。
- 朋友模式：暖米色纸卷轴，200 道题，三个层次分别为 70、70、60 道。
- 两个模式独立保存已抽题目、所选层次和当前题目，界面不显示题目数量。
- 每次打开先显示对象选择页；抽题页左上角可返回切换对象。
- 每轮不重复抽题，抽完后可以重新开始当前层次。
- 轻柔的点击、滚动与落定音效，支持静音。
- 放松提示约每 15 秒切换。
- 手机竖屏、横屏、平板和电脑响应式布局。
- 尊重系统减少动态效果设置。
- 支持添加到手机主屏幕，显示纸卷爱心图标与「再靠近一点」名称。

## 添加到主屏幕

在 iPhone 的 Safari 中打开线上网址，点分享 → 添加到主屏幕 → 添加。旧快捷方式若仍显示旧图标，移除旧快捷方式后重新添加。安卓可在浏览器菜单选择添加到主屏幕。

`manifest.webmanifest` 与 `icons/` 提供安装名称和图标，部署时需与 `index.html` 一起上传。主屏幕版仍需要联网加载，不提供离线缓存。

## 数据与隐私

所有题目、样式和音效代码内置于 HTML 文件，欢迎页插画位于 `assets/welcome-art.png`。只在当前浏览器保存已抽题目及音效偏好，不记录聊天回答，不使用分析或广告追踪。不同设备和浏览器的进度不互通。托管服务可能记录常规访问日志。

## 维护与验证

直接修改 `index.html`。题目位于 `topic-data` JSON 数据块。朋友题库的审阅原文位于 `friends-topics.txt`（前 70 行为第一层，第 71–140 行为第二层，其余为第三层），网页使用 `friend-data` 中的内置数据，不需额外联网请求题目。修改朋友题后需同步更新 HTML 内的数据。使用 `node test.cjs` 检查两套题库、分层、模式隔离、原有进度兼容、抽题、存储、提示轮换和音效调度。

GitHub Pages 发布源：`main` 分支根目录。浏览器实际显示与音频表现还取决于系统字体、音量及浏览器设置。

## 2026-11-12 定位更新

面向已有接触、还不够熟悉、愿意继续了解的两个人。首页直接说明用途与步骤，无需额外开屏。心动之间包含好感与暧昧阶段，不预设情侣身份。三个话题类型：日常喜好、经历与想法、相处与期待；显示当前类型说明。两人都可回答，不想聊可以再抽。修订过于私密、沉重和长期关系维护题，保留题目 ID、分类与存储键。题库阅读稿已同步更新；历史设计图仅作视觉参考。
