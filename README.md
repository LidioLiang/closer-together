# 再靠近一点

温柔的双人聊天网页：选择一个层次，抽一个话题，慢慢认识彼此。

## 使用

通过 GitHub Pages 打开网页，或下载 `index.html` 后直接用浏览器打开。无需登录，也不需要安装。

- 暖粉色纸卷轴，三个聊天层次。
- 每轮不重复抽题，抽完后可以重新开始当前层次。
- 轻柔的点击、滚动与落定音效，支持静音。
- 放松提示约每 15 秒切换。
- 手机竖屏、横屏、平板和电脑响应式布局。
- 尊重系统减少动态效果设置。

## 数据与隐私

所有题目、样式和音效代码内置于单个 HTML 文件。只在当前浏览器保存已抽题目及音效偏好，不记录聊天回答，不使用分析或广告追踪。不同设备和浏览器的进度不互通。托管服务可能记录常规访问日志。

## 维护与验证

直接修改 `index.html`。题目位于 `topic-data` JSON 数据块。使用 `node test.cjs` 检查题库、抽题、存储、提示轮换和音效调度。

GitHub Pages 发布源：`main` 分支根目录。浏览器实际显示与音频表现还取决于系统字体、音量及浏览器设置。
